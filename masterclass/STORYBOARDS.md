# Storyboards — Frame-by-Frame Shot Lists
*The visual "frames" for every video. Each frame = one on-screen moment. The 🟦 GAMMA OUTLINE slides in each script ARE the slide frames — paste them into Gamma to render the real visuals. This file sequences those slides with the standard bookend + demo frames so an editor can assemble each video without guessing.*

> I can't render video files or images here — these are production-ready storyboards + the slide text that generates the actual frames in Gamma.

---

## Universal frame pattern (every video follows this)
| # | Frame type | Duration | What's on screen |
|---|---|---|---|
| 1 | **Intro card** | 0:00–0:03 | Brand bumper: logo + course name + module number |
| 2 | **Title frame** | 0:03–0:08 | Video title (the Gamma "Title" slide) + host lower-third if on cam |
| 3–N | **Content slides** | varies | One Gamma slide per concept (the 🟦 outline lines) |
| D | **Demo screen** | the bulk | Full-screen REAL Claude recording for each ▶️ [DEMO] cue (with auto-zoom) |
| R | **Recap card** | ~10 sec | 2–3 bullet recap |
| A | **Action card** | ~8 sec | The ✅ action + "⏸ pause and do this now" |
| Z | **Outro card** | ~5 sec | "Next: [next video]" + brand bumper |

**Timing rules:** slide frames 4–8 sec each; demo frames run as long as the action takes (speed-ramp dead time in Descript); never leave a static slide up while talking for >15 sec — cut to the demo.
**Visual style:** one Gamma theme; brand colours; captions burned in; cursor highlight + click sounds on demos; lower-third only on host segments.
