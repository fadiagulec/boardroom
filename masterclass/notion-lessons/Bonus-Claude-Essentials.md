## ▶️ B1 — Chat vs Cowork vs Code
*[ video ]* · Think/brainstorm → **Chat** · files/data → **Cowork** · build a tool → **Code**. Not sure? Ask Chat.

## ▶️ B2 — Which model (Haiku / Sonnet / Opus)
*[ video ]* · **Haiku 4.5** = fast/cheap · **Sonnet 4.6** = your default · **Opus 4.8** = deepest thinking. Start with Sonnet, escalate to Opus.

## ▶️ B3 — What Claude can do
*[ video ]* · Q&A · analyse docs/images · live web research · code + charts · writing · **Artifacts** (interactive, in a side panel).

## ▶️ B4 — Why Claude over other LLMs
*[ video ]* · It pushes back and flags weak logic instead of just agreeing — a reviewer, not a cheerleader.

## ▶️ B5 — Prompt engineering core
*[ video ]* · Be direct · give it a role · use XML tags · few-shot examples · "think step by step" · control length/format · "answer if known, else say you don't know." (📋 *Prompt Library → Foundations: 30 Principles*)

## ▶️ B6 — Prompt chaining
*[ video ]* · Break big tasks into Research → Outline → Draft → Review, passing each step's output to the next.

## ▶️ B7 — Skills, deep dive
*[ video ]* · A `SKILL.md` (name + description = trigger) that auto-activates. Enable in Settings → Capabilities (paid plan).

## ▶️ B8 — Projects, deep dive
*[ video ]* · Instructions (always-on) vs knowledge files (reference) vs chats (not shared). One Project per domain.

## ▶️ B9 — Connectors / MCP
*[ video ]* · Connect Notion, Drive, GitHub, Slack via 2-min OAuth — no more copy-paste. Reading is stronger than writing; scope permissions tightly.
