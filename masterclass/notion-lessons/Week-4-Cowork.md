## ▶️ Lesson 4.3 — Give Cowork a brain (CLAUDE.md + MEMORY.md)
*[ Paste your HeyGen video here ]*
Cowork can't read your Projects — it starts cold each session unless you give it a file.

**Do this:**
1. In **Chat**, run the **Build your CLAUDE.md** prompt (📋 *Prompt Library → Week 4*). Review it, save it as `CLAUDE.md` in your Cowork folder.
2. In **Cowork**, paste this:

**📋 Copy this — create MEMORY.md:**
```
Create an empty file called MEMORY.md in my Cowork folder.
The file should contain only this text:

# Memory — Cross-Project Learnings
*Decisions, preferences, and patterns from working sessions. Updated when something changes how we work. Not a session log — only durable learnings.*

Do not add anything else.
```

**✅** - [ ] CLAUDE.md saved - [ ] MEMORY.md created

## ▶️ Lesson 4.5 — Run, fix, schedule
*[ Paste your HeyGen video here ]*
**Do this:**
1. Open Cowork with your folder selected; paste the prompt; run it.
2. First run won't be perfect — give specific feedback, run v2.
3. Then schedule it:

**📋 Copy this:**
```
Turn this brief into a scheduled task that runs [your time, e.g. daily at 6:30am].
```
> Note: scheduled tasks run only while your computer is awake.
