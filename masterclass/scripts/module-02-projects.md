## V2.3 — The master workspace prompt (8 min)

🟦 GAMMA OUTLINE
```
Title: Hand it to Claude — the architect prompt
Slide: It runs a strategy session, not a form
Slide: Finalises architecture → interviews you → drafts instructions → tells you what to upload
Slide: One project at a time. Let it push back. Stop at the handover.
Rule: Max 2 projects per chat
```

NARRATION
> Now you hand the work to Claude. The prompt below this video is a workspace architect — it walks through a structured process: it finalises your architecture, interviews you for each project, drafts the custom instructions, and tells you exactly what to upload. One project at a time.
>
> Three things before you run it. One: this is a strategy session, not a form — Claude will ask questions and push back on vague answers. Let it; the quality of your instructions depends entirely on the quality of context you give. Two: don't try to finish everything in one sitting — two well-built projects beat six rushed ones. Three: when Claude says the chat is getting long and offers a handover, take it. Quality drops once the context window fills.
>
> So: open a new chat — not inside a project yet — on Sonnet with extended thinking. Paste your project list into the prompt, and let's build your first one together.

## V2.4 — The handover: never lose context (5 min)

🟦 GAMMA OUTLINE
```
Title: When Claude "gets full"
Slide: Signs — vaguer answers, repetition, forgetting details
Slide: It's not getting worse. It's full.
Slide: The fix — a handover document (30 seconds)
Slide: Also use it when switching models
```

NARRATION
> Claude has a context window — it can only hold so much before it starts losing the thread. You'll notice it: answers get vaguer, it repeats things, it forgets details. That's not Claude getting worse — it's just full.
>
> The fix is a handover document. Before a long conversation gets too long, you ask Claude to capture everything — who you are, what you're working on, decisions locked in, what's next — in a document you paste into a fresh chat. Takes thirty seconds, and you never lose progress. Use the exact same prompt whenever you want to switch models, too.
